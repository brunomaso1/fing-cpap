# Probabilidad y estadística utilizando software - FING

Este curso de actualización profesional tiene como objetivo brindar a los participantes los conocimientos y habilidades necesarias para aplicar conceptos fundamentales de probabilidad y estadística utilizando herramientas de software modernas. A lo largo del curso, se explorarán técnicas estadísticas esenciales y se aprenderá a implementar estas técnicas mediante el uso de software especializado, facilitando así el análisis de datos en diversos contextos profesionales.

Se utilizó Matlab y Octave.

## Temario

1. Variables aleatorias y simulación.
2. Estimación puntual.
3. Test de hipótesis.
4. Estadística no paramétrica.
