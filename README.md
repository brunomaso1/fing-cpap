# Ingeniería de software avanzada - FING

## Descripción del curso

Este curso contó con tres ejes principales:
- Calidad de Datos y Big Data en Ingeniería de Software
- Ingeniería de Software cuántica
- Desafíos de Arquitectura de Software de Sistemas habilitados para AA

## Temario

1. Calidad de Datos y Big Data en Ingeniería de Software
    1. Conceptos básicos de Calidad de Datos.
        1. Dimensiones y métricas, Modelos de Calidad de datos, Data Profiling.
        2. Ejemplos con participación de la audiencia.
    2. Líneas de investigación actuales en el área de calidad de datos.
        1. Contextos, Metodologías/procesos
        2. Perspectivas y desafíos
    3. Calidad de datos en Big Data
        1. Arquitecturas, preparación de datos
        2. Desafíos.
    4. Calidad de datos en Ingeniería de Software
        1. Integración de los dos mundos, desafíos.
        2. Interacción entre los procesos de calidad de datos y los de Ingeniería de Software.
        3. Experiencias de investigación en nuestros equipos
    5. Estudio de caso con un dataset provisto por nosotros.
        1. Aplicación de una metodología de calidad de datos, ejecución de data profiling utilizando una herramienta especializada, construcción de un pequeño modelo de calidad.

2. Ingeniería de Software cuántica
    1. Introducción y principios de computación cuántica
        1. aspectos básicos y necesarios para desarrollar software cuántico basado en circuitos.
    2. Algoritmos cuánticos:
        1. algoritmos clásicos de computación cuántica.
    3. Entornos de programación cuántica:
        1. visión general de entornos de desarrollo cuántico.
        2. Presentación del entorno que se utilizará en la parte práctica del tutorial.
    4. Primer programa cuántico:
        1. ejemplos guiados con los asistentes para comenzar a programar software cuántico.
    5. Mini-proyecto:
        1. Los asistentes desarrollarán un pequeño problema acotado al tutorial, y lo ejecutarán.

3. Desafíos de Arquitectura de Software de Sistemas habilitados para AA
    1. Desafíos de Arquitectura de Software para sistemas AA
        1. Prácticas de Arquitectura de Software y sistemas AA
        2. Patrones de Arquitectura y tácticas para atributos de calidad (AQ) importantes para AA
        3. Capacidad de monitoreo y confianza como AQ directivas
        4. Co-arquitectura y co-versionado
    2. Ejercicios prácticos
        1. comprendiendo que es significativo arquitecturalmente y que no lo es
        2. escribiendo atributos de calidad (AQ) relevantes para sistemas haiblitados para AA
        3. Temporizador para ejercicio relacionado con la monitorización
